# Параллельное соединение резисторов

Интерактивное обучающее приложение на Python + PyQt6.

Анимированная демонстрация параллельного соединения двух резисторов с измерительными приборами, синхронизированная по тайм-кодам (0–30 сек).

## Требования

- Python 3.10+
- PyQt6

## Установка

```bash
python3 -m venv venv
source venv/bin/activate   # macOS/Linux
pip install PyQt6
```

## Запуск

```bash
python main.py
```

## Управление

| Кнопка | Действие |
|--------|----------|
| ▶ Play | Запустить демонстрацию |
| ⏸ Pause | Поставить на паузу |
| ⟳ Reset | Сбросить в начало |
| 🎵 Аудио | Загрузить аудиофайл (WAV/MP3) |

Слайдер **R₂** в панели управления активен в фазе 7 (интерактивный режим, t=18–30 с). Можно менять сопротивление вручную.

## Добавление своей озвучки

1. Подготовьте аудиофайл (WAV или MP3) длительностью ровно 30 секунд.
2. Нажмите **🎵 Аудио** и выберите файл.
3. Нажмите **Play** — аудио синхронизируется с тайм-кодами.

Если аудио короче 30 с, после его окончания анимация продолжит идти по внутреннему таймеру.

## Формат тайм-кодов

Тайм-коды хранятся в `main.py` (список `TIMELINE_EVENTS`), а также в файле `timeline_events.json`.

Каждое событие содержит:
- `time` — время в секундах (float)
- `action` — тип действия
- `text` / `id` / `value` — параметры

Доступные действия: `subtitle`, `show_resistor`, `show_meter`, `show_source`, `draw_wires`, `set_r2`, `show_readings`, `show_formula`, `start_interactive`, `stop_interactive`.

## Формулы расчёта

```
I₁ = 0.12 A    (фиксировано)
U  = 12 V      (фиксировано)
I₂ = U / R₂
I₃ = I₁ + I₂
Rэкв = U / I₃
```
